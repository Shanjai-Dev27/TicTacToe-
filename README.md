If you're using windows all you should do is , 
  1. download msys2 gcc compiler
  2. install and make it global in your system
  3. Open the tictactoe.c file and compile it using gcc tictactoe.c -o tictactoe
  4. Run the tictactoe.exe file .\tictactoe.exe
